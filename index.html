Comandos Essenciais

git init

Criar um novo repositório no Git

git add .

Adicionar alterações ao repositório

git commit -m "[Mensagem de Commit]"

Adiciona mensagens nas alterações do commit

git push -u origin main

Empurra as alterações salvas para o repositório criado

git fetch

Verifica se o repositório remoto tem modificações em relação ao local

git pull

Puxa as mudanças do repositório para sua máquina

git clone

Clona os mudanças do repositório git para a máquina local

git remote add origin

Conecta o repositório local ao repositório remoto


Dica: Lembrar do espaço antes do -m/u
